# 对标 SOP 课程更新说明（上传新视频 / 新增案例）

> 用途：以后持续上传新的「对标视频」或新增「量房 / 开工 / 成品案例 / 巡检 / 见客户」这几类下的案例时，按本文档操作即可更新到小程序。
> 前提：本机已安装 Node.js 24+，工程位于 `D:/4.3杨磊/垒/聚梦传媒小程序`。

---

## 一、课程是怎么进入小程序的（链路）

```
原始课程 JSON（电脑本地）
   │  npm run import:course    ← 清洗 + 生成 course.json
   ▼
miniprogram/data/course.json   （课程「真源」数据）
   │  npm run build（内含 build-course.mjs）
   ▼
course.ts → 编译成 JS          （微信运行时只读 JS，不读 JSON）
```

视频本身**不打包进小程序**，只记录相对路径（如 `videos/xxx.mp4`、`clips/xxx.mp4`、`assets/xxx.jpg`），播放时通过 `config.ts` 的 `mediaBase` 拼成完整 HTTPS 地址。

## 二、新增一个案例 / 镜头，需要两步

### 第 1 步：把新视频放进媒体目录

把视频/封面放到媒体根目录（本机：`../output/pdf/厨房视频照拍手册/`）下对应子目录：

| 类型 | 目录 | 说明 |
|---|---|---|
| 完整原片 | `videos/` | 每个案例一条完整视频（如 `videos/123.mp4`） |
| 分镜片段 | `clips/` | 每个镜头一条片段（如 `clips/abc.mp4`）+ 封面图 `clips/abc.jpg` |
| 示意图 | `assets/` | 站位/构图示意图 |

### 第 2 步：在原始课程 JSON 里加对应条目

编辑 `../output/pdf/源文件/厨房视频照拍手册/手机课程.json`，按现有结构新增：

```jsonc
{
  "categories": [ { "id":"measure","name":"量房","desc":"...","lessonIds":[1] } ],
  "lessons": [{
    "id": 2,                     // 新案例，id 唯一
    "name": "新案例名",
    "task": "让人看懂：...",       // 会自动去掉「让人看懂：」前缀展示
    "need": "...", "takeaway": "...",
    "file": "videos/新视频.mp4",   // 完整原片
    "duration": 120.5,
    "shots": [{
      "title":"...", "where":"...", "frame":"...", "action":"...",
      "say":"...", "stop":"...", "check":"...",
      "ref":0, "end":5, "keep":5,
      "clip":"clips/新片段.mp4", "clipPoster":"clips/新片段.jpg", "image":"assets/新图.jpg"
    }]
  }]
}
```

新增到某分类，就把该案例的 `id` 加进对应分类的 `lessonIds` 数组。

## 三、更新命令（在工程根目录 PowerShell 执行）

```powershell
npm run import:course    # 从原始 JSON 重新生成 course.json
npm run verify:media     # 核验所有媒体文件都在、哈希一致
npm run build            # 重新编译
npm test                 # 跑回归测试
```

全绿后，在微信开发者工具里刷新即可看到新案例。

> 视频文件本身在上线阶段需另上传到对象存储/CDN（`mediaBase` 指向的地址），并保持 `videos/clips/assets` 目录结构不变。详见 `docs/上线部署指南.md`。

## 四、五类分类说明（当前锁定）

| id | 名称 | 说明 |
|---|---|---|
| `measure` | 量房 | 问需求、量尺寸、说改法 |
| `start` | 开工 | 把开工说清楚 |
| `case` | 成品案例 | 改前改后对照、验收、回访 |
| `meet` | 见客户 | 先听需求、再约下一步 |
| `inspect` | 巡检 | 探班看进度与细节 |

新增案例请归入上述五类之一；如需新增第六类，需同步改 `app` 端分类渲染与后端校验（联系开发）。

## 五、常见问题

- **改了 JSON 但小程序没变？** 一定是漏了 `npm run build`。运行时只读编译后的 JS，不读 JSON。
- **视频播放不出来？** 检查媒体文件是否在 `mediaBase` 指向的服务器/CDN 上，路径是否与 `course.json` 里的相对键一致。
- **忘记「让人看懂：」前缀要不要手删？** 不用，展示层会自动去掉，源数据保留即可。
