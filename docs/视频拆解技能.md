# 视频拆解成照拍 SOP

技能入口：`skills/jumeng-video-sop/SKILL.md`，调用名为 `$jumeng-video-sop`。

以后把视频和同一条视频的 SRT 发给 AI，再说：

> 用 $jumeng-video-sop，把这个视频拆成小学生也能一步步看懂的照拍 SOP，检查后导入老师后台草稿。

AI 会对照字幕和画面，讲清每一镜为什么拍、站在哪里、手机拍什么、怎么做、怎么说、何时停、怎么检查。镜头数量随内容确定，不强凑六步。看不清或不能确认的地方会列出来。

默认先交出照拍说明和课程文件；你要求上传时，再生成完整片、分镜片段和封面并导入草稿。草稿在老师后台可见，学员看不到。你明确要求发布后，才进入学员目录。

技能不会替你调用付费转录或生成 API，不会覆盖旧案例，不会把视频、字幕、学员数据同步到公开仓库。代码同步和课程发布是两件事，见[换电脑与 AI 接手](换电脑与AI接手.md)。

本轮已验证构造素材的导入、发布和开发者工具播放链路，也做了独立试跑：完整视频加字幕、仅字幕缺少视频、与视频拆解无关的会员定价请求。仅字幕不会被说成已经看过画面；与拆解无关的任务不会套用本技能。真实视频及读者照拍效果尚待验证。
