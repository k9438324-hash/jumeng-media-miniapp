## 二、后台配置项（周一认证后你在微信公众平台操作）

这些必须你本人在 **微信公众平台（mp.weixin.qq.com）→ 小程序后台** 填写，我无法代操作：

### 1. 《用户隐私保护指引》

路径：小程序后台 → 设置 → 服务内容声明 → 用户隐私保护指引 → 更新

需要填写的「收集的信息」类型：
- **微信身份标识（OpenID）** —— 用于识别学习记录与权限
- **用户输入的文字内容** —— 发送至 AI 服务生成回复
- **学习进度数据** —— 阅读进度同步

### 2. 类目选择

小程序后台 → 设置 → 基本设置 → 服务类目。你的业务属于：
- 建议类目：**教育 > 教育信息服务** 或 **工具 > 效率**（按实际资质选择）
- ⚠️ 涉及「培训/在线教育」可能需《增值电信业务经营许可证》或办学资质，如不确定，选「教育信息服务」这类免资质类目更稳妥

### 3. 服务器域名（合法域名）

小程序后台 → 开发 → 开发设置 → 服务器域名 → request 合法域名

填入你部署后端后的 HTTPS 域名（这一步要在服务器 + 域名 + HTTPS 配好后做，见《上线部署指南》）。
