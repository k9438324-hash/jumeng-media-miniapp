# 老师后台（本地使用）

已有两个入口：小程序顶部的「老师后台」按钮，以及原来的电脑网页后台。两者共用服务端的课程和学员数据。本机环境仍须保持电脑服务开启，尚未部署公网服务。

## 从小程序进入

在 SOP、聚梦AI、会员任一页，点击顶部「老师后台」，输入老师设置的密码。进入后可以新增或编辑 SOP、上传媒体、保存草稿、发布或下架，并管理学员、续期、增加次数及启停。

服务端配置 TEACHER_PASSWORD_HASH（管理密码的 SHA256 摘要），本机真实设置只保存在忽略提交的 server/.env；换服务器后须单独配置并重启。仓库和小程序代码均不包含实际密码。未配置时禁止管理登录。正式微信模式仍需先将老师微信账号加入获准使用的学员名单。

后台权限绑定当前登录身份，有效期 30 分钟；点击退出、关闭管理页或重启服务后须重新验证。密码连续错误 5 次，同一来源 15 分钟内不能继续尝试。每个管理接口都会校验登录身份与后台权限，不能直接绕过密码页请求。正式手机使用需按部署说明配置 HTTPS API 地址和合法域名。

小程序内单文件上传最多 20 MB，较大文件可使用电脑网页后台。原始 iPhone 视频未必是 MP4，当前只接受 MP4、JPEG、PNG；不支持的文件需先转换格式。

## 打开

1. 在工程目录先运行 `npm ci`、`npm run setup`。
2. 双击工程里的 `打开老师后台.cmd`，保持弹出的终端开启。
3. 双击 `server/data/打开老师后台.url` 进入后台。自定义 DB_PATH 时，快捷方式生成在数据库所在目录。
4. 另开终端运行 `npm run dev`，为小程序提供服务；开发者工具导入工程根目录。

快捷方式含随机管理口令，不能分享或上传。重启后台后旧口令失效，重新打开快捷方式。后台与小程序服务必须使用相同的 DB_PATH；操作前备份数据库。

## SOP

选择案例编辑，或点新增。先保存草稿，再发布；草稿不会改变学员当前看到的版本。下架后从线上目录移除，草稿仍保留。学员登录后刷新课程获取发布版本，断网时保留本地目录并提示。

每个镜头的 logic 用大白话解释为什么这样拍；where/frame/action/say/stop/check 分别记录站位、画面、动作、说法、何时结束、检查方法。文字课可以暂不传视频。后台不会自动拆解视频，也不会调用付费模型。

本机上传支持 MP4、JPEG、PNG，每文件最多 200MB，文件保存在数据库旁的 uploads 目录。该上传和本地播放用于开发；正式手机使用仍须配置可访问的 HTTPS API、媒体托管地址与微信合法域名。上传不会自动部署到 CDN。

## 学员与额度

输入学员 OpenID 添加学员，选择学员后可开通、续期、增加次数、停用并查看使用记录。模拟环境可使用模拟设备标识，不可当作真实微信身份。

续期天数与增加次数可分别为零，但不能同时为零；没有有效会员时必须给出有效天数。未到期续期累加，已到期重开不结转旧余额。重复点开通会重复增加，请先刷新核对。

停用后学员旧会话也不能继续请求。会员到期或次数耗尽会阻止新 AI 生成。当前没有自动微信支付、退款、人民币钱包或成本统计；不要将手动开通记录当作真实收款凭证。

## 后续简化方向

用户希望通过技能提交资料、拆解 SOP 并导入，以减少逐镜填写。该技能尚待方案确认和实现；现有表单仍可用于校对与管理。
