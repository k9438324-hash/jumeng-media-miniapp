# 聚梦传媒小程序 · 上线部署指南

> 目标：让小程序正式上架、学员能用。
> 本指南从「买服务器」到「提审」全程覆盖，按顺序做即可。
> 密钥（AppSecret、DeepSeek Key）**只在服务器上填，绝不发到聊天里**。

---

## 一、上架全景（先看这张图，心里有数）

```
买域名 → 买服务器 → 解析域名 → 部署后端 → 上传视频
   → 微信后台配合法域名 → 手机联调验收 → 提审 → 发布
```

你当前状态：主体已认证 ✅ ｜ 视频已备好 ✅ ｜ 服务器/域名待买 ⚠️

---

## 二、第一步：买域名 + 服务器（约 ¥100 首年）

### 2.1 买什么

| 项 | 买什么 | 价格参考 |
|---|---|---|
| 域名 | `.cn` 或 `.top`（实名后即可） | 首年 ¥9~30 |
| 服务器 | 腾讯云轻量应用服务器 **2核2G** 国内（成都/广州） | 新用户活动价约 ¥50~80/年 |
| 系统 | **Ubuntu 22.04** 或 Debian（别买 Windows） | — |

> 💡 找「新用户活动」页买服务器，常有 50 元上下的首年价，比月付划算。
> SSL 证书用腾讯云免费 DV 证书（¥0）。

### 2.2 备案（国内服务器必须）

1. 在腾讯云控制台「备案」入口提交域名备案。
2. 主体你已认证，按提示上传营业执照等材料即可。
3. 备案一般 **7~20 天**下发，期间不能绑定域名访问（可先做后面的本地准备工作）。

> 想跳过备案？可改用香港/海外服务器，但速度慢、域名钱省不掉，**不推荐**（见方案对比，最便宜且最稳是「国内+备案」）。

### 2.3 解析域名

备案通过后，到域名解析控制台添加一条 **A 记录**：

```
主机记录：api（或 @）
记录类型：A
记录值：你的服务器公网 IP
```

---

## 三、第二步：部署后端

### 3.1 上传部署脚本到服务器

把本仓库 `scripts/deploy-server.sh` 上传到服务器（用 scp / 宝塔 / 直接粘贴均可），然后：

```bash
# 在服务器上，root 用户
DOMAIN=api.你的域名.com bash deploy-server.sh
```

脚本会自动完成：装 Node24 + Nginx → 拉代码 → 构建 → 生成环境变量文件 → 配 HTTPS → systemd 常驻启动。

### 3.2 填密钥（脚本会提示你）

脚本运行到第 3 步会生成 `/opt/jumeng.env`，你需要填：

```
WECHAT_APP_ID=你的AppID（wx0d79451e6dd4b6b9）
WECHAT_APP_SECRET=AppSecret（微信后台「开发管理」里拿）
WECHAT_ALLOWED_OPENIDS=学员openid1,学员openid2
DEEPSEEK_API_KEY=你的DeepSeekKey
```

> AppSecret 在微信公众平台 → 开发 → 开发管理 → 开发设置里查看/重置。
> 学员 openid 怎么拿：见下方「收集学员 openid」。

### 3.3 验证

```bash
curl https://api.你的域名.com/health
```

返回包含 `身份=wechat · AI=deepseek` 即成功。

---

## 四、第三步：上传视频

8 条视频在本地。上传到对象存储（腾讯云 COS）或 CDN：

1. 开通腾讯云 COS，建一个存储桶（建议私有读 + CDN 加速）。
2. 上传 `videos/`、`clips/`、`assets/` 下的媒体文件，保持目录结构。
3. 拿到 HTTPS 访问前缀，例如 `https://media.你的域名.com/课程前缀`。

然后改 `miniprogram/config.ts`：

```ts
export const config = {
  apiBase: 'https://api.你的域名.com',
  authMode: 'wechat',
  mediaBase: 'https://media.你的域名.com/课程前缀',
};
```

重新 `npm run build`。

> 媒体文件清单见 `docs/DEPLOYMENT.md`，保留 `videos/xxx.mp4`、`clips/xxx.mp4`、`assets/xxx.jpg` 结构即可。

---

## 五、第四步：微信后台配置

1. **合法域名**：微信公众平台 → 开发 → 开发管理 → 开发设置 → 服务器域名：
   - request 合法域名：`https://api.你的域名.com`
   - downloadFile 合法域名：`https://media.你的域名.com`（视频下载用）
2. **类目**：确认已选对服务类目（教育培训类需对应资质，你主体已认证）。
3. **隐私保护指引**：配置用户隐私保护指引（涉及登录、用户信息）。

---

## 六、第五步：手机联调验收

1. 微信开发者工具 → 预览 → 扫码在真机打开。
2. 用真实学员微信登录，走通：看 SOP → 切镜 → 播放视频 → 带进 AI → 发消息。
3. 确认：视频能播、AI 能回、历史能存、额度正常。

> 这一步通过，才代表「学员能用」，模拟器通过不算。

---

## 七、第六步：提审 + 发布

1. 微信开发者工具 → 上传代码 → 填版本号。
2. 微信公众平台 → 版本管理 → 提交审核。
3. 审核通过后 → 发布。

提审前自查清单：
- [ ] request / downloadFile 合法域名已配 HTTPS
- [ ] 隐私保护指引已配置
- [ ] 类目正确、资质齐全
- [ ] 视频在 HTTPS 域名可访问
- [ ] 真机验收通过
- [ ] 有 AI 内容标识（AI 生成内容声明）
- [ ] 内容安全（涉政/涉黄过滤）已处理

---

## 八、收集学员 openid（发布后）

1. 学员用自己的微信打开小程序，会触发 `wx.login` 拿 code。
2. 管理员在服务器终端跑：
   ```bash
   node --env-file=/opt/jumeng.env /opt/jumeng/scripts/resolve-openid.mjs
   ```
   输入学员的 code，得到 openid。
3. 把 openid 加进 `/opt/jumeng.env` 的 `WECHAT_ALLOWED_OPENIDS`，重启服务：
   ```bash
   systemctl restart jumeng
   ```

> 注意：正式学员的 code 必须在**其本人登录环境**取得，不能用管理员自己的 code 代替。

## 九、费用小结

| 项 | 一次性/年 | 说明 |
|---|---|---|
| 域名 | ¥9~30/年 | 必买 |
| 服务器 | ¥50~80/年（活动价）或 ¥50~80/月 | 必买 |
| SSL 证书 | ¥0 | 免费 DV |
| 对象存储/CDN | 按量，初期很低 | 视频流量 |
| DeepSeek API | 按 token，很小 | 学员聊天 |

**首次总投入约 ¥100 左右，之后主要是服务器月费 + 视频流量。**
