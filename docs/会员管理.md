# 会员与使用记录

2026-10-30：新增 AI 会员期限、套餐次数、最近 50 条调用记录和管理员命令。底部第三项「会员」进入账户页。账户页点击「登录并查看」，复用现有微信登录；模拟环境明确标注模拟。微信模式仍要求学员在许可名单内。

## 权益规则

- 新增学员和旧数据库里的学员均不会自动获得期限或额度；部署前需明确为原学员开通。不会自动把曾经的付费承诺转换为三个月。
- 每次新 AI 请求在事务内检查期限、套餐余额及每日上限，然后扣 1 次并记录流水。同一 requestId 重放返回原任务，不重复扣次。
- 延续已有计次规则：失败、主动停止均不退次数，新请求重试另计；页面明确展示。这是调用次数制，不是人民币钱包或 token 精确账单。
- 到期只阻止新的 AI 生成；已登录学员仍可查看账户、历史对话和旧任务。SOP 不新增期限限制；已移出白名单者仍被原权限机制拒绝。
- 期限按服务器时间计算；页面统一北京时间。天数指连续 24 小时，不等于自然月。
- 未到期续期：从原到期时间增加天数，余额累加；已到期续期：从操作时刻重新起算，旧套餐余额不结转。本期已用对应当前连续有效期，历史流水保留。
- 使用列表只包含本版本新增的流水；升级前的历史调用保留在旧每日计数里，不伪造逐次记录。

## 管理员操作

在可信服务器终端、项目根目录执行。使用与服务端完全一致的环境和 DB_PATH，先备份数据库。没有新增公网管理接口。Key、AppSecret 不经聊天或命令参数传递。

```powershell
npm run build
# 核对 server/.env 的 DB_PATH 与正在运行服务一致
npm run member -- show --openid 学员OpenID
# 以下仅为开通命令示例，90 天、100 次不是已确定的商品定价
npm run member -- grant --openid 学员OpenID 90 100 "学员赠送体验"
# 未到期时延长 30 天并增加 50 次；已到期时新开一期
npm run member -- grant --openid 学员OpenID 30 50 "学员续期"
```

学员可在[老师后台](老师后台.md)添加并启用，也可沿用 WECHAT_ALLOWED_OPENIDS 配置（环境名单变化须重启服务）。数据库学员启停状态优先。命令成功提交后，学员刷新账户即可看到新权益。命令重复执行会再次增加天数和额度，因此执行后先 show 核对，不要盲目重跑。

本机开发可用 `--device` 代替 `--openid`，其值是客户端存储 `jumeng:mockDevice` 的原始字符串；仅 mock 身份模式允许。第一次先启动服务创建数据库，再开通对应设备。管理员命令打开数据库时不执行启动恢复，不会把运行中的生成任务标成失败。

## 接口与验证边界

`GET /account` 使用现有 Bearer 会话；仅返回当前身份的会员、今日次数、每日上限、最近 50 条调用记录，不接受客户端 owner。无权限、到期和额度耗尽都由生成接口再次校验，修改手机时间或页面不会绕过。

已有本地会员管理后台；尚未接入自动支付、退款、人民币余额、token 成本统计或豆包。真实微信身份、真机界面与付费 API 尚未在本轮测试。
